# Checklist Kartika Cyber Hackathon 2026

Status tanggal: 21 Oktober 2026. Tandai kotak saat tugas selesai.

## Pendaftaran dan tim

- [v] Bentuk tim beranggotakan 2-3 orang.
- [v] Pastikan semua anggota memiliki akun CODEPOLITAN.
- [v] Ketua tim mendaftarkan tim lewat halaman hackathon CODEPOLITAN.
- [v] Lengkapi nama tim, data anggota, dan ide solusi.
- [v] Simpan konfirmasi pendaftaran dan tenggat resmi dari penyelenggara.

## Pembekalan dan pengerjaan

- [ ] Catat insight dari webinar pembekalan pertama (19 Oktober; sudah lewat — pastikan catatan/sertifikat akses tersimpan bila tersedia).
- [ ] Ikuti webinar pembekalan kedua pada 27 Oktober.
- [v] Pastikan ruang lingkup solusi sesuai kategori Defensive Shield dan kebutuhan pengamanan IT/OT.
- [v] Selesaikan purwarupa dan pastikan dapat dijalankan untuk demo (dashboard peta + tabel pemeriksaan, konsol red team dengan profil asal penyerang, rule engine 8 aturan, panel AI + tombol "Pulihkan situs", alarm sirine, mode dampak situs dummy, laporan insiden siap cetak lengkap bagian A-G).
- [v] Uji alur utama dan siapkan data/demo yang dapat diulang (test otomatis 6/6 lulus `npm test`: detector, inventory `.test`, vendor CSS; E2E browser konsol → dashboard, analisis, pulihkan, laporan PDF).
- [v] Pastikan demonstrasi hanya menggunakan target dan data sintetis, bukan sistem nyata.
- [v] Jalankan `npm start`; server berhasil berjalan di `http://localhost:3000` (bind `127.0.0.1`; tersedia `start.bat` / `stop.bat`).

- [ ] Tunjukkan relevansi dan manfaat solusi (25%).
